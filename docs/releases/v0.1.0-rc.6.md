# Release v0.1.0-rc.6

## Title

Mobile Dashboard Polish and Faster Workspace Funding Handoff

## Description

This release candidate bundles the latest mobile-first dashboard refinements together with a faster workspace funding confirmation flow. It focuses on making the app feel more native on phones, shortening the post-payment waiting state, and keeping the funding handoff clear after Paystack returns.

## Included Changes

- mobile dashboard styling updates with tighter spacing, grouped quick actions, and swipe-friendly insight sections
- compact header and layout adjustments for smaller screens
- workspace funding confirmation now returns to the funding page sooner instead of lingering on the verifying state
- workspace funding verification and provider timeout handling tuned for a faster handoff
- updated client payout test instructions to include platform owner/admin checks

## Verification

The following checks passed locally before this release candidate was prepared:

- `npm run build`

## Known Notes

- Workspace funding verification still depends on the Paystack verification response, but the confirmation page now falls back to the funding page more quickly if verification is slow.
- The outgoing payouts release and supporting runbooks remain available in the existing payout docs under `docs/payouts/`.
