# Release v0.1.0-rc.5

## Title

Outgoing Payouts Platform Release Candidate

## Description

This release candidate promotes the outgoing payouts work from `develop` into a release-ready branch. It includes the wallet funding foundation, provider-backed bill payouts, scheduled payouts, approval controls, payout limits, admin reporting, audit visibility, and the client smoke-test runbook for the full pay flow.

## Included Changes

- wallet funding through Paystack with callback verification and webhook settlement
- outgoing payout execution from `Pay now` and `Schedule Payment`
- payout approvals, role-based controls, and workspace-level payout limits
- payout freeze controls for admin emergency holds
- payout history, confirmations, CSV export, and admin reporting views
- audit logging and support lookup visibility for payout actions
- client-facing payout smoke-test instructions
